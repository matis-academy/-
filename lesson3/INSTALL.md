# Как разместить 3D-тренажёры на странице урока 3 (Bricks)

Три виджета стоят в разных разделах урока. Скрипт подключается **один раз** на страницу,
а в каждом месте, где нужен тренажёр, ставится пустой блок с атрибутом.

## Шаг 1. Загрузить модель на хостинг (один раз)

Файл `lesson3/models/woman.glb` (1 МБ) загрузить через файловый менеджер хостинга или FTP,
например в папку `wp-content/uploads/ml/`. Получится адрес вида
`https://matis.academy/wp-content/uploads/ml/woman.glb` — проверьте, что он открывается (браузер предложит скачать файл).

> Медиатека WordPress по умолчанию не принимает .glb, поэтому — через файловый менеджер.
> Если загрузить некуда, см. «Запасной вариант» внизу.

## Шаг 2. Вставить код страницы (один раз)

Редактор Bricks → ⚙ **Настройки страницы → Пользовательский код → Body (footer) scripts**. Вставить по порядку:

```html
<script>window.ML_STUDIO_MODEL = "https://matis.academy/wp-content/uploads/ml/woman.glb";</script>
```

и сразу под ним — всё содержимое файла `lesson3/bricks-code.html` (он уже начинается с `<script>`).

Сохранить страницу.

## Шаг 3. Поставить виджеты в нужные места урока

В каждом разделе, где должен быть тренажёр:

1. Внутри контейнера раздела (`ml-col`) добавить элемент **Block** — пустой, без детей, без высоты и цветов.
2. **Стиль → Атрибуты → Добавить атрибут**: имя `data-ml-widget`, значение:

| Раздел урока | Значение атрибута |
|---|---|
| Движение камеры | `studio-move` |
| Тренажёр · двигай солнце вокруг модели | `studio-sun` |
| Крупности | `studio-shots` |

3. Старые виджеты в этих разделах удалить.

Блоки могут стоять где угодно и в любом порядке — между текстом, видео, тестом. Виджет сам растягивается
на ширину колонки и сам задаёт высоту.

## Как это работает на странице

- Каждый виджет запускается, только когда ученик доскроллил до него (примерно за полтора экрана).
  Наверху страницы 3D не грузится вообще.
- Three.js и модель скачиваются один раз и используются всеми тремя виджетами.
- Ушёл виджет с экрана — он перестаёт рисовать и не тратит батарею.
- В редакторе Bricks блоки выглядят пустыми — это нормально, пользовательский код там не запускается.
  Проверять — на живой странице.

## Проверка после вставки

На ПК и телефоне: дойти до каждого раздела, увидеть сцену с девушкой на площади, покликать кнопки.
Если вместо девушки из модели видна упрощённая нарисованная фигура — не открылся файл `woman.glb`:
проверьте адрес в строке из шага 2.

## Обновление

Когда тренажёры меняются, заменяется только содержимое `bricks-code.html` в коде страницы (шаг 2).
Блоки на странице трогать не нужно.

## Запасной вариант без загрузки файла

Вместо строки `window.ML_STUDIO_MODEL = "…"` вставить содержимое `lesson3/models/woman-embedded.js`,
обернув его в `<script>…</script>`. Минус — +1,4 МБ текста в коде страницы.
