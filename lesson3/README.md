# 3D-тренажёры для урока 3

Интерактивные 3D-виджеты для страницы `matis.academy/mini-course-3/` на общем движке (Three.js r128).
Героиня — девушка в красном летнем платье, место действия — итальянская пьяцца: охристые дома
со ставнями и арками, колокольня, фонтан, кафе, лимоны в горшках, кипарисы и тосканские холмы.

**В работе три виджета:** «Движение камеры», «Двигай солнце вокруг модели», «Крупности».
«Поставь модель» и «Композиция кадра» пока отложены — код остаётся в сборке, но не дорабатывается.

| Виджет | Атрибут блока | Что делает ученик |
|---|---|---|
| Поставь модель | `data-ml-widget="studio-pose"` | выбирает одну из 9 поз (солдатик, вес на ногу, руки в карманах, скрещённые руки, рука у лица, шаг, у стены, сидя, через плечо), разворачивает модель и голову, обходит её камерой, включает проверку силуэтом. Виджет проверяет позу: разворот корпуса, вес на одной ноге, просветы между руками и телом, видно ли лицо |
| Композиция кадра | `data-ml-widget="studio-compose"` | тянет героя по кадру, меняет крупность, направление взгляда, высоту камеры, передний план (ветка, плечо собеседника) и фон (столб за головой). Разбор кадра: правило третей, запас по взгляду, воздух над головой, глаза на верхней трети, столб «из головы», горизонт через шею |
| Движение камеры | `data-ml-widget="studio-move"` | 8 движений: панорама, тилт, наезд, отъезд, проезд с идущим героем, облёт, кран, зум. Вид из камеры и анимированная схема сверху или сбоку, скорость, описание «как / зачем / чем снять / частая ошибка» |
| Двигай солнце вокруг модели | `data-ml-widget="studio-sun"` | тянет солнце по кругу на карте сверху, меняет высоту солнца, включает отражатель. Видно, как меняются свет на лице, контур и тень на земле; вставка «вид со стороны» показывает солнце и тень |
| Крупности | `data-ml-widget="studio-shots"` | 7 планов: сверхобщий, общий, средне-общий, средний, средне-крупный, крупный, сверхкрупный. Камера плавно переезжает, ползунок меняет крупность непрерывно, схема тела показывает, где проходит край кадра, и предупреждает, если он режет суставы |

Демо трёх рабочих виджетов: `index.html` (для локального просмотра нужен интернет — Three.js грузится с cdnjs).

## Как вставить в урок (Bricks)

1. Содержимое `bricks-code.html` вставить в **Настройки страницы → Пользовательский код → Body (footer) scripts**
   страницы третьего урока. Стили и Three.js скрипт подключает сам.
2. В нужных местах урока поставить пустые **Block** с атрибутом `data-ml-widget` и значением из таблицы.
   Старые виджеты, которые заменяются, удалить.
3. Для «Поставь модель» можно задать стартовую позу: `data-start="contra"` (по умолчанию),
   `soldier`, `pockets`, `crossed`, `think`, `walk`, `wall`, `sit`, `shoulder`.

## Нагрузка

- Сервер отдаёт только текст скрипта (~110 КБ, со сжатием ~30 КБ). Three.js (~600 КБ, ~150 КБ со сжатием)
  загружается один раз с cdnjs и кэшируется браузером.
- Каждый виджет рисует кадр только когда что-то меняется или идёт анимация, и останавливается вне экрана.

## Разработка

Исходники в `src/`, сборка: `node build.js` → `ml-studio.js` и `bricks-code.html`.

## Модель девушки

Виджеты показывают готовую модель девушки в кремовом кружевном платье (`models/woman.glb`):
49 тыс. треугольников, скелет из 27 костей, встроенные анимации Idle и Walk, без текстур.
Файл сжат (квантование геометрии): 1,07 МБ, ≈0,45 МБ со сжатием на сервере.
`models/woman-embedded.js` — та же модель внутри JS (data-URI, ~1,4 МБ), если файл .glb некуда загрузить.

Пока модель грузится или если она недоступна, показывается встроенная нарисованная фигура.
Загрузчик glTF (Three.js r128) подгружается с jsDelivr только когда модель указана.
Подходит любая модель со скелетом Mixamo-формата (кости Hips, Head, HeadTop_End, LeftLeg…) и клипами idle/walk.

### Как подключить на сайте

**Вариант А — файл .glb (рекомендую).**
1. Загрузить `models/woman.glb` на сайт, например в `wp-content/uploads/ml/` через файловый менеджер хостинга
   или FTP (медиатека WordPress по умолчанию не принимает .glb).
2. В «Пользовательском коде» страницы **перед** основным скриптом добавить:
   `<script>window.ML_STUDIO_MODEL = "https://matis.academy/wp-content/uploads/ml/woman.glb";</script>`
   (или атрибут `data-model="…"` у каждого блока виджета).

**Вариант Б — без отдельного файла.** Вставить содержимое `models/woman-embedded.js` в `<script>…</script>`
перед основным скриптом. Минус — +1 МБ текста в коде страницы.

### Пересборка модели

`tools/retarget.mjs` переносит клипы idle/walk с Xbot на Michelle через мировые повороты костей,
`tools/optimize.mjs` сжимает текстуры в WebP и квантует геометрию (нужны `@gltf-transform/*` и `sharp`).
