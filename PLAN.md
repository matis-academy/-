# Второй мозг: Obsidian + Hermes Agent

План сборки персональной системы «работа / финансы / здоровье / жизнь в одном месте».

**Исходные данные:**
- Устройства: iPhone, Mac, мини-ПК на Windows
- Hermes живёт на **мини-ПК с Windows** (включён 24/7); Mac и iPhone — клиенты
- Модели: OpenRouter, дешёвые
- Заметки и задачи уже в Obsidian
- Здоровье: Huawei Watch Fit 4 Pro → Huawei Health → Apple Health
- Финансы: ручной ввод пару раз в месяц

---

## 1. Архитектура в одной картинке

```
 ┌──────────────────────── iPhone ─────────────────────────┐
 │ Obsidian · Telegram · Huawei Health → Apple Health      │
 │                     └─ «Команды»: раз в день пишут      │
 │                        метрики здоровья в хранилище     │
 └───────┬───────────────────┬─────────────────────────────┘
         │ Obsidian Sync     │ сообщения, голосовые, фото
         ▼                   ▼
 ┌──────────── мини-ПК Windows (24/7) ───────────────┐      Mac
 │  📁 Obsidian vault  ◄── единственный источник     │ ◄──── Obsidian
 │        ▲            правды (обычные .md файлы)    │ Sync  (клиент)
 │        │ читает / пишет                           │
 │  🤖 Hermes Agent (в WSL2) ── Telegram-шлюз, cron, │
 │        │                     скиллы, своя память   │
 │  git — история всех правок агента, откат          │
 └────────┼──────────────────────────────────────────┘
          ▼
 ☁️ OpenRouter (дешёвые LLM · ZDR · без обучения на твоих данных)
```

**Роли:**

| Компонент | Роль | Нужен? |
|---|---|---|
| **Obsidian** | Хранилище всего: заметки, задачи, дневник, финансы, здоровье. Обычные markdown-файлы, лежат у тебя | ✅ ядро |
| **Hermes Agent** (Nous Research, open source) | «Руки»: читает и пишет в хранилище, утренние сводки, разбор входящих, ответы по твоим заметкам, Telegram-бот | ✅ ядро |
| **OpenRouter** | «Мозги» для Hermes: дешёвые модели по API | ✅ |
| **Obsidian Sync** | Синхронизация мини-ПК ↔ Mac ↔ iPhone (iCloud плохо дружит с Windows, Syncthing слабый на iPhone) | ✅ ~$4–5/мес |
| **Telegram** | Главный интерфейс: написал / надиктовал / прислал скриншот → агент разложил | ✅ |
| **«Команды» iPhone** (Shortcuts) | Раз в день берут из Apple Health сон, шаги, пульс, вес и пишут заметку в хранилище | ✅ бесплатно |
| **git** | История изменений: если агент что-то испортил — откат | ✅ |
| **Notion** | **Пока не нужен.** Ты уже живёшь в Obsidian. Понадобится только для общих баз с командой/клиентами — у Hermes есть скилл `notion` | ⏸ позже |
| Google Calendar / Gmail | Календарь в утренней сводке (скилл `google-workspace`) | ⏸ по желанию |

## 2. Семь правил, без которых второй мозг превращается в свалку

1. **Один источник правды — хранилище Obsidian.** Hermes — исполнитель, а не хранилище. Всё важное оседает в `.md` файлах, а не в переписке с ботом.
2. **Чёткие зоны.** Есть папки «мои» и папки «агента». В твои заметки агент только *дописывает* (раздел `## 🤖 Hermes` в дневной заметке) или *предлагает* правки. Так нет конфликтов синхронизации и контроль остаётся у тебя.
3. **Сырые данные не трогаем.** PDF анализов, скриншоты, выгрузки лежат как есть, агент делает из них выводы в отдельных файлах.
4. **Единый формат frontmatter** (`type`, `date`, `area`, `status` + метрики). Это превращает заметки в базу данных для Dataview и агента.
5. **Цифры считает скрипт, а не модель.** Дешёвые модели ошибаются в арифметике. Суммы по финансам и средние по здоровью — через Python-скрипты, которые Hermes напишет и сохранит как скилл.
6. **По одной сфере за раз.** Сначала ядро и ежедневный цикл, потом здоровье, потом финансы.
7. **Еженедельный обзор обязателен.** Без него любая система умирает за месяц. Агент готовит черновик, ты 15 минут его просматриваешь.

## 3. Структура хранилища

Текущее хранилище **не ломаем**: сначала смотрим, что есть, потом постепенно раскладываем по новой схеме (с помощью агента и с git-страховкой).

```
Vault/
├── AGENTS.md              ← инструкция для агента: правила, зоны, форматы
├── 00-Inbox/              ← всё входящее (Telegram, клиппер, голосовые) — агент разбирает
├── 01-Daily/              ← дневные заметки 2026-10-07.md (дневник, задачи дня, настроение)
├── 02-Projects/           ← проекты с целью и сроком
├── 03-Areas/              ← сферы жизни без срока
│   ├── Work/
│   ├── Finance/
│   │   ├── Finance.md         ← дашборд (Dataview)
│   │   ├── categories.md      ← категории + синонимы («пятёрочка», «лента» → Продукты)
│   │   ├── Ledger/2026-10.md  ← расходы/доходы месяца (таблица, ведёт агент)
│   │   ├── Reports/           ← месячные отчёты агента
│   │   └── Budgets.md · Subscriptions.md · Goals.md
│   ├── Health/
│   │   ├── Health.md          ← дашборд
│   │   ├── Metrics/           ← ежедневные заметки от «Команд» (сон, шаги, пульс, вес)
│   │   ├── Labs/              ← анализы: PDF + заметка с выписанными значениями
│   │   ├── Doctors/ · Meds.md · Symptoms.md
│   ├── Family/ · Learning/ · Home/ ...
├── 04-Resources/          ← статьи, конспекты, справочники
├── 05-Archive/            ← завершённое
├── 90-Agent/              ← зона агента
│   ├── Briefings/         ← утренние сводки
│   ├── Reviews/           ← недельные/месячные обзоры
│   └── log.md             ← журнал действий агента (только дописывать)
├── Templates/
└── Attachments/
```

**Пример заметки здоровья** (`03-Areas/Health/Metrics/2026-10-07.md`, пишут «Команды»):

```yaml
---
type: health-daily
date: 2026-10-07
sleep_h: 7.2
steps: 8450
resting_hr: 58
weight_kg:
source: huawei→apple-health
---
```

**Плагины Obsidian:** Dataview, Templater, Tasks, Periodic Notes, Calendar, Obsidian Git (на мини-ПК), Web Clipper (расширение браузера).

## 4. План по этапам (~4 недели)

### Этап 0 — Подготовка (1 вечер)
- [ ] Полный бэкап текущего хранилища (zip на внешний диск или в облако)
- [ ] **Мини-ПК как сервер:** электропитание → сон «Никогда»; в BIOS включить автозапуск после пропадания питания; в Windows Update задать «период активности», чтобы перезагрузки были ночью; Obsidian в автозагрузке
- [ ] Obsidian Sync (Standard): подключить хранилище на мини-ПК → Mac → iPhone. Других синхронизаторов (iCloud, OneDrive, Syncthing) на этой же папке быть не должно
- [ ] Git for Windows + плагин Obsidian Git с автокоммитом раз в час (`.obsidian/workspace*` в `.gitignore`). Удалённый репозиторий — только **приватный** (там будут финансы и здоровье) или вообще без него

### Этап 1 — Ядро хранилища (2–3 дня)
- [ ] Аудит текущего хранилища: какие папки, сколько заметок, что живое
- [ ] Создать структуру из раздела 3 (существующие заметки пока не двигать)
- [ ] Шаблоны: дневная заметка, проект, встреча, анализ, месячный отчёт
- [ ] Написать `AGENTS.md` (черновик — в приложении A)
- [ ] Установить плагины, собрать дашборды «Сегодня», «Финансы», «Здоровье»

### Этап 2 — Hermes на мини-ПК (1–2 дня)

**Как ставить на Windows.** У Hermes есть два пути:
- **WSL2 (рекомендую)** — внутри Windows работает настоящий Linux (Ubuntu). Самый проверенный вариант для шлюза 24/7 и cron
- **Нативный Windows** — установка одной командой PowerShell, но официально это *early beta*; в документации прямо сказано про шероховатости с не-ASCII символами в консоли, а у нас всё по-русски. Подходит, чтобы быстро попробовать

Шаги (WSL2):
- [ ] OpenRouter: ключ с **лимитом расходов** (например $10/мес), в настройках приватности включить **Zero Data Retention** и **запрет обучения на данных**
- [ ] `wsl --install` (Ubuntu), включить systemd
- [ ] В Ubuntu: `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
- [ ] `hermes model` → OpenRouter. Прогнать 2–3 дешёвые модели **с хорошим tool calling и нормальным русским** на одной задаче («разбери Inbox по AGENTS.md»). Слабая модель = агент путается в файлах. Для тяжёлых задач (недельный обзор, разбор анализов) держать одну модель посильнее и переключаться через `/model`
- [ ] Безопасность в `~/.hermes/config.yaml`: `approvals.mode: manual`, `approvals.cron_mode: deny`
- [ ] Хранилище лежит на стороне Windows, из WSL оно видно как `/mnt/c/Users/<ты>/.../Vault`. Включить скилл `obsidian`, прописать этот путь (по данным сообщества — переменная `OBSIDIAN_VAULT_PATH` в `~/.hermes/.env`) и сказать агенту читать `AGENTS.md` перед любой работой с хранилищем
- [ ] Telegram: бот через @BotFather → `hermes gateway setup` → в `TELEGRAM_ALLOWED_USERS` **только твой числовой ID** (узнать у @userinfobot)
- [ ] Голосовые: `stt: local` (faster-whisper прямо на мини-ПК, бесплатно, звук никуда не уходит)
- [ ] Шлюз как служба (`hermes gateway install`) + автозапуск WSL при старте Windows через Планировщик заданий. **Проверить**: шлюз живёт после закрытия терминала и после перезагрузки ПК
- [ ] `hermes doctor`, потом тест: «запиши идею …», «что у меня в проекте X?», голосовое

> Эту часть удобно делать вместе со мной прямо на мини-ПК: поставь там Claude Desktop (или Claude Code и запусти `claude remote-control` в папке хранилища) — сессия появится в приложении Claude на телефоне, и я смогу выполнять команды на самом ПК.

### Этап 3 — Ежедневный цикл (неделя обкатки)
Расписания задаются Hermes обычным текстом в чате («каждый день в 7:30 делай …»).

| Когда | Что делает агент |
|---|---|
| 07:30 | **Утренняя сводка** → в `90-Agent/Briefings/` + в Telegram: задачи на сегодня, просроченное, сон/шаги/пульс за ночь, остаток бюджета месяца, 1–3 приоритета |
| в течение дня | Захват: «идея …» → Inbox, «вес 78.4» → метрики, голосовые → расшифровка в Inbox |
| 21:30 | **Вечерний опрос** в Telegram: что сделал, настроение и энергия 1–10 → в дневную заметку |
| ночью | Разбор Inbox: раскладывает *то, в чём уверен*, остальное — список «куда положить?» в утреннюю сводку |
| вс 19:00 | **Недельный обзор** → `90-Agent/Reviews/2026-W41.md`: работа, деньги, здоровье, зависшие проекты |

### Этап 4 — Здоровье (неделя)
- [ ] **Huawei → Apple Health:** в Huawei Health включить передачу в «Здоровье» (Профиль/Я → Сторонние сервисы → Apple Health), в приложении «Здоровье» разрешить Huawei Health все категории

## 5. Безопасность (агент с доступом к деньгам и здоровью)

- Telegram-бот отвечает **только** твоему ID
- `approvals.mode: manual` — опасные команды только после твоего подтверждения; для cron — `deny`
- git на хранилище + бэкап = любую правку агента можно откатить
- OpenRouter: ZDR + запрет обучения + лимит расходов на ключе
- Агент **не отправляет** письма/сообщения и **не платит** от твоего имени — только черновики
- Осторожно с чужим текстом: письма и веб-страницы могут содержать prompt injection. На старте не давать агенту одновременно читать почту и что-то отправлять

## 7. Что ещё нужно уточнить

1. **Мини-ПК:** ты за ним работаешь как за обычным компьютером или он стоит только как сервер? (Если только сервер — Obsidian Sync можно запускать без интерфейса, через официальный Headless Sync внутри WSL.) Сколько у него RAM?
2. **Текущее хранилище:** примерно сколько заметок, какая структура и плагины, что хочется сохранить?
3. **Работа:** чем занимаешься и какие рабочие инструменты нужно подтянуть (календарь, почта, что-то ещё)?
4. **Валюта:** одна (рубли?) или несколько?

- Свободно: 90-Agent/**, 03-Areas/Finance/Ledger/**, 03-Areas/Finance/Reports/**,
  03-Areas/Health/Labs/*.md (новые заметки), 00-Inbox (создавать)
- Только дописывать: раздел "## 🤖 Hermes" в дневной заметке; 90-Agent/log.md
- Только с подтверждения: перенос/переименование/удаление любых моих заметок
- Никогда: 03-Areas/Health/Metrics/** (их пишет iPhone), файлы в Attachments
  (сырые данные), .obsidian/**

## Финансы
- Ввод 2 раза в месяц: текст «категория сумма, ...» или скриншоты из банка

- Доход со знаком +, расход без знака

## Форматы
- Каждая новая заметка с frontmatter: type, date, area, status

- Ссылки — [[wikilinks]], теги — #area/finance и т.п.

## Числа
- Любые суммы, средние, отчёты — только через скрипт (python), не в уме

## Каждое действие
- Дописывай строку в 90-Agent/log.md: время, что сделал, какие файлы
