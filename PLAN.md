# Второй мозг: Obsidian + Hermes Agent

План сборки персональной системы «работа / финансы / здоровье / жизнь в одном месте».

**Исходные данные (из ответов):**
- Устройства: Mac + iPhone + Windows
- Hermes живёт на домашнем Mac (24/7)
- Модели: OpenRouter, дешёвые
- Заметки и задачи уже в Obsidian

---

## 1. Архитектура в одной картинке

```
                ┌──────────────── iPhone ────────────────┐
                │ Obsidian · Telegram · Apple Health     │
                └───────┬──────────────┬─────────────┬───┘
                        │ Obsidian     │ сообщения,  │ Health.md
                        │ Sync         │ голосовые   │ (выгрузка здоровья)
                        ▼              ▼             ▼
 Windows ◄─ Obsidian ─► ┌───────────── домашний Mac (24/7) ─────────────┐
 (просто    Sync        │  📁 Obsidian vault  ◄── единственный источник  │
  клиент)               │        ▲     правды (обычные .md файлы)        │
                        │        │ читает / пишет                        │
                        │  🤖 Hermes Agent ── Telegram-шлюз, cron,       │
                        │        │            скиллы, своя память         │
                        │        ▼                                        │
                        │  git (история всех правок агента, откат)       │
                        └────────┼───────────────────────────────────────┘
                                 ▼
                     ☁️ OpenRouter (дешёвые LLM, ZDR, без обучения на данных)
```

**Роли:**

| Компонент | Роль | Нужен? |
|---|---|---|
| **Obsidian** | Хранилище всего: заметки, задачи, дневник, финансы, здоровье. Обычные markdown-файлы, лежат у тебя | ✅ ядро |
| **Hermes Agent** (Nous Research, open source) | «Руки»: читает и пишет в хранилище, утренние сводки, разбор входящих, ответы на вопросы по твоим заметкам, Telegram-бот | ✅ ядро |
| **OpenRouter** | «Мозги» для Hermes: дешёвые модели по API | ✅ |
| **Obsidian Sync** | Синхронизация Mac ↔ Windows ↔ iPhone (iCloud плохо работает с Windows, Syncthing слабый на iPhone) | ✅ ~$4–5/мес |
| **Telegram** | Главный интерфейс: надиктовал / написал → агент разложил | ✅ |
| **Health.md** (iPhone + Mac) | Apple Health → ежедневные markdown-заметки с метриками в хранилище | ✅ |
| **git** | История изменений: если агент что-то испортил — откат | ✅ |
| **Notion** | **Пока не нужен.** Ты уже живёшь в Obsidian. Понадобится только для общих баз с командой/клиентами — у Hermes есть скилл `notion`, подключим тогда | ⏸ позже |
| Google Calendar / Gmail | Календарь в утренней сводке (скилл `google-workspace`) | ⏸ по желанию |

## 2. Семь правил, без которых второй мозг превращается в свалку

1. **Один источник правды — хранилище Obsidian.** Hermes — исполнитель, а не хранилище. Всё важное оседает в `.md` файлах, а не в чате с ботом.
2. **Чёткие зоны.** Есть папки «мои» и папки «агента». В твои заметки агент только *дописывает* (в раздел `## 🤖 Hermes` дневной заметки) или *предлагает* правки. Так нет конфликтов синхронизации и ты сохраняешь контроль.
3. **Сырые данные не трогаем.** Банковские CSV, PDF анализов, выгрузки — лежат как есть, агент делает из них выводы в отдельных файлах.
4. **Единый формат frontmatter** (`type`, `date`, `area`, `status` + метрики). Это превращает заметки в базу данных, по которой работают Dataview и агент.
5. **Цифры считает скрипт, а не модель.** Дешёвые модели ошибаются в арифметике. Суммы по финансам и средние по здоровью — через Python-скрипты, которые Hermes сам напишет и сохранит как скилл.
6. **По одной сфере за раз.** Сначала ядро и ежедневный цикл, потом здоровье, потом финансы. Не всё сразу.
7. **Еженедельный обзор обязателен.** Без него любая система умирает за месяц. Агент готовит черновик — ты 15 минут его просматриваешь.

## 3. Структура хранилища

Твоё текущее хранилище **не ломаем**: сначала смотрим, что есть, потом постепенно раскладываем по новой схеме (с помощью агента и с git-страховкой).

```
Vault/
├── AGENTS.md              ← инструкция для агента: правила, зоны, форматы
├── 00-Inbox/              ← всё входящее (Telegram, клиппер, голосовые) — агент разбирает
├── 01-Daily/              ← дневные заметки 2026-10-07.md (дневник, задачи дня, настроение)
├── 02-Projects/           ← проекты с целью и сроком
├── 03-Areas/              ← сферы жизни без срока
│   ├── Work/
│   ├── Finance/
│   │   ├── Finance.md         ← дашборд (Dataview)
│   │   ├── categories.md      ← категории + правила авторазметки
│   │   ├── Imports/           ← сырые выгрузки из банков (не трогать)
│   │   ├── Ledger/2026-10.md  ← транзакции месяца
│   │   ├── Reports/           ← месячные отчёты агента
│   │   └── Subscriptions.md · Budgets.md · Goals.md
│   ├── Health/
│   │   ├── Health.md          ← дашборд
│   │   ├── Metrics/           ← ежедневные выгрузки Health.md (сон, шаги, пульс, вес)
│   │   ├── Labs/              ← анализы: PDF + заметка с выписанными значениями
│   │   ├── Doctors/ · Meds.md · Symptoms.md
│   ├── Family/ · Learning/ · Home/ ...
├── 04-Resources/          ← статьи, конспекты, справочники
├── 05-Archive/            ← завершённое
├── 90-Agent/              ← зона агента
│   ├── Briefings/         ← утренние сводки
│   ├── Reviews/           ← недельные/месячные обзоры
│   └── log.md             ← журнал действий агента (только дописывать)
├── Templates/
└── Attachments/
```

**Frontmatter дневной заметки (пример):**

```yaml
---
type: daily
date: 2026-10-07
mood: 7          # из вечернего опроса в Telegram
energy: 6
spent_total: 2350  # агент пересчитывает скриптом из Ledger
---
```

**Плагины Obsidian:** Dataview, Templater, Tasks, Periodic Notes, Calendar, Obsidian Git (на Mac), Web Clipper (расширение браузера).

## 4. План по этапам (~4 недели)

### Этап 0 — Подготовка (1 вечер)
- [ ] Сделать полный бэкап текущего хранилища (zip-архив + Time Machine)
- [ ] Решить вопрос «Mac работает 24/7»: если это MacBook — всегда на зарядке, отключить сон (`sudo pmset -a sleep 0` или приложение Amphetamine), Obsidian в автозапуске
- [ ] Оформить Obsidian Sync (Standard), подключить хранилище на Mac → Windows → iPhone. Других синхронизаторов (iCloud, Syncthing) на этой же папке быть не должно
- [ ] `git init` в хранилище на Mac + плагин Obsidian Git с автокоммитом раз в час (`.obsidian/workspace*` — в `.gitignore`). Удалённый репозиторий — только **приватный** (там будут финансы и здоровье), либо вообще без него

### Этап 1 — Ядро хранилища (2–3 дня)
- [ ] Аудит текущего хранилища: какие папки, сколько заметок, что живое
- [ ] Создать структуру из раздела 3 (существующие заметки пока не двигать)
- [ ] Шаблоны: дневная заметка, проект, встреча, анализ, месячный отчёт
- [ ] Написать `AGENTS.md` (черновик — в приложении A)
- [ ] Установить плагины, собрать дашборды «Сегодня», «Финансы», «Здоровье»

### Этап 2 — Hermes на Mac (1–2 дня)
- [ ] OpenRouter: создать ключ с **лимитом расходов** (например $10/мес), в настройках приватности включить **Zero Data Retention** и **запрет обучения на данных**
- [ ] Установить Hermes: `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
- [ ] `hermes model` → OpenRouter. Выбрать 2–3 дешёвые модели **с хорошим tool calling** и прогнать на одной и той же задаче («разбери Inbox по AGENTS.md»). Слабая модель = агент путается в файлах. Для тяжёлых задач (недельный обзор, разбор анализов) держать одну модель посильнее и переключаться через `/model`
- [ ] Безопасность в `~/.hermes/config.yaml`: `approvals.mode: manual`, `approvals.cron_mode: deny` (опасные команды в фоне запрещены)
- [ ] Подключить хранилище: включить скилл `obsidian`, прописать путь к хранилищу (по данным сообщества — переменная `OBSIDIAN_VAULT_PATH` в `~/.hermes/.env`), сказать агенту читать `AGENTS.md` перед любой работой с хранилищем
- [ ] Telegram: бот через @BotFather → `hermes gateway setup` → в `TELEGRAM_ALLOWED_USERS` **только твой числовой ID** (узнать у @userinfobot)
- [ ] Голосовые: распознавание речи `stt: local` (faster-whisper прямо на Mac, бесплатно, звук никуда не уходит)
- [ ] Шлюз как фоновая служба: `hermes gateway install`, проверка: `hermes doctor`
- [ ] Тест: «запиши идею …», «что у меня в проекте X?», голосовое сообщение

### Этап 3 — Ежедневный цикл (неделя обкатки)
Расписания задаются Hermes обычным текстом в чате («каждый день в 7:30 делай …»).

| Когда | Что делает агент |
|---|---|
| 07:30 | **Утренняя сводка** → в `90-Agent/Briefings/` + в Telegram: задачи на сегодня, просроченное, сон/шаги за ночь, остаток бюджета месяца, 1–3 приоритета |
| в течение дня | Захват: «идея …» → Inbox, «потратил 1200 продукты» → Ledger, «вес 78.4» → метрики, голосовые → расшифровка в Inbox |
| 21:30 | **Вечерний опрос** в Telegram: что сделал, настроение и энергия 1–10, что потратил → в дневную заметку |
| ночью | Разбор Inbox: раскладывает по папкам *то, в чём уверен*, остальное — список «куда положить?» в утреннюю сводку |
| вс 19:00 | **Недельный обзор** → `90-Agent/Reviews/2026-W41.md`: работа, деньги, здоровье, зависшие проекты |

### Этап 4 — Здоровье (неделя)
- [ ] Health.md (iPhone + Mac): ежедневная выгрузка Apple Health в `03-Areas/Health/Metrics/` — сон, шаги, пульс покоя, вес, тренировки (во frontmatter)
- [ ] Дашборд Health.md: Dataview-таблица за 14/30 дней + графики
- [ ] Анализы: кидаешь PDF/фото в Telegram → агент кладёт файл в `Labs/` и создаёт заметку со значениями, нормами и сравнением с прошлыми результатами
- [ ] `Meds.md`, `Doctors/`, `Symptoms.md` — журнал лекарств, врачей, симптомов (быстрый ввод через Telegram)
- [ ] В недельный обзор: тренды сна и веса, корреляции с настроением/энергией

### Этап 5 — Финансы (неделя)
- [ ] Список счетов и валют, `categories.md` с правилами («Пятёрочка/Lidl → Продукты»)
- [ ] Импорт: раз в неделю/месяц выгрузка CSV из банка → `Finance/Imports/` → агент **скриптом** парсит, размечает по категориям, дописывает в `Ledger/ГГГГ-ММ.md`, спорные операции спрашивает
- [ ] Быстрый ввод наличных и мелочей через Telegram
- [ ] 1-го числа: месячный отчёт (доход/расход по категориям, против бюджета, подписки, аномалии)
- [ ] `Subscriptions.md` — агент напоминает о списаниях заранее

### Этап 6 — Работа (неделя)
- [ ] Проекты в `02-Projects/` со статусом, сроком и следующим шагом
- [ ] Шаблон заметки встречи; после встречи — голосовое в Telegram → агент делает конспект и задачи
- [ ] (По желанию) Google Calendar в утреннюю сводку через скилл `google-workspace` — начать с доступа **только на чтение**

### Этап 7 — Потом, когда ядро работает (месяц 2+)
- Notion — только если появится совместная работа с людьми
- Локальная модель (Ollama на Mac) для финансов/здоровья, если захочется, чтобы эти данные вообще не уходили в облако
- Внешний провайдер памяти Hermes (Honcho / Mem0) — не нужен сразу: долговременная память = само хранилище, а встроенной памяти Hermes (MEMORY.md / USER.md) хватает для предпочтений
- Паттерн «LLM-wiki» Карпатого: агент ведёт тематические wiki-страницы по твоим источникам в `04-Resources/`

## 5. Безопасность (агент с доступом к деньгам и здоровью)

- Telegram-бот отвечает **только** твоему ID
- `approvals.mode: manual` — опасные команды только после твоего подтверждения; cron — `deny`
- git на хранилище + Time Machine = любую правку агента можно откатить
- OpenRouter: ZDR + запрет обучения + лимит расходов на ключе
- Агент **не отправляет** письма/сообщения и **не платит** от твоего имени — только черновики
- Осторожно с чужим текстом: письма и веб-страницы могут содержать prompt injection. На старте не давать агенту читать почту и одновременно иметь право что-то отправлять

## 7. Что ещё нужно уточнить

1. **Финансы:** какие банки и страна (есть ли выгрузка CSV/Excel), сколько валют, только личные или ещё бизнес? Пользуешься ли приложением учёта (Дзен-мани, CoinKeeper и т. п.)?
2. **Здоровье:** есть ли Apple Watch или другой трекер (Oura, Garmin, Mi Band)? Что важнее всего отслеживать: сон, вес, тренировки, анализы, хронические вещи?
3. **Mac-сервер:** это MacBook или стационарный (mini/iMac)? Apple Silicon? Сколько RAM (влияет на локальное распознавание речи и возможную локальную модель)?
4. **Текущее хранилище:** примерно сколько заметок и есть ли уже структура/плагины, которые хочется сохранить?
5. **Работа:** что это за работа и какие рабочие инструменты нужно подтянуть (календарь, почта, что-то ещё)?
6. **Язык:** заметки и общение с агентом на русском? (Влияет на выбор модели: не все дешёвые модели хорошо пишут по-русски)

## Приложение A. Черновик `AGENTS.md`

```markdown
# Правила для агента (Hermes)

## Кто я
<имя>, пишу по-русски. Сферы: работа, финансы, здоровье, семья, обучение.

## Структура
- 00-Inbox — входящие, ты разбираешь
- 01-Daily — дневные заметки ГГГГ-ММ-ДД.md
- 02-Projects, 03-Areas, 04-Resources, 05-Archive — PARA
- 90-Agent — твоя зона

## Где тебе можно писать
- Свободно: 90-Agent/**, 03-Areas/Finance/Ledger/**, 03-Areas/Finance/Reports/**,
  03-Areas/Health/Labs/*.md (новые заметки), 00-Inbox (создавать)
- Только дописывать: раздел "## 🤖 Hermes" в дневной заметке; 90-Agent/log.md
- Только с подтверждения: перенос/переименование/удаление любых моих заметок
- Никогда: Finance/Imports/**, PDF/файлы в Attachments (сырые данные), .obsidian/**

## Форматы
- Каждая новая заметка с frontmatter: type, date, area, status
- Даты ISO: 2026-10-07. Деньги — числом, валюта отдельным полем
- Ссылки — [[wikilinks]], теги — #area/finance и т.п.

## Числа
- Любые суммы, средние, отчёты — только через скрипт (python), не в уме
- В отчёте указывай, по каким файлам считал

## Каждое действие
- Дописывай строку в 90-Agent/log.md: время, что сделал, какие файлы
- Если не уверен, куда положить, — не клади, а спроси в утренней сводке
```
