# Симулятор съёмки в разное время суток

Интерактивный виджет для страницы курса «Видеосъёмка для начинающих» (matis.academy/mini-course-2/).
Ученик выбирает время суток — **рассвет, утро, полдень, закат, синий час** — и настраивает камеру,
а виджет показывает, как выглядел бы кадр, и оценивает его.

Демо: откройте `index.html` в браузере.

## Что симулируется

| Настройка | Что видно в кадре |
|---|---|
| Выдержка | смаз движения велосипедиста; при короткой выдержке — «стробоскоп» (движение рывками) |
| Частота кадров 25/50/100 | норма по правилу 180° (1/50, 1/100, 1/200); 50 и 100 к/с — замедление на таймлайне 25p |
| Диафрагма | глубина резкости (размытие фона, боке фонарей), виньетирование на открытой диафрагме |
| ISO | яркость и цифровой шум (больше в тенях, с цветными «зёрнами») |
| ND-фильтр | гасит свет, не меняя выдержку и диафрагму |
| Баланс белого | цвет кадра; «Авто» на закате и в синий час убивает атмосферу |

Экспозиция считается по реальной формуле: `EV = log2(N²/t) − log2(ISO/100) + ND`.
Яркость каждой сцены задана в EV (рассвет ≈ 10, утро ≈ 13,6, полдень ≈ 14,6, закат ≈ 11,6, синий час ≈ 5,6),
поэтому, например, в полдень на f/2.8 и 1/50 без ND кадр будет пересвечен на 6 стопов — как в жизни.

Сцена рендерится в линейном HDR: солнце, фонари и фары ярче белого, поэтому при недоэкспозиции
они остаются яркими, а при переэкспозиции небо «выбивается» в белое. Сенсор обрезает света,
поверх — кривая с мягким плечом, как у видеопрофиля Rec.709.

Монитор камеры: REC и таймкод, экспонометр (−3…+3), гистограмма, зебра, сетка третей, рамка автофокуса.

Справа — «Оценка кадра» (экспозиция, правило 180°, шум, баланс белого, глубина резкости)
и карточка «Свет» с характеристиками времени суток, советами и заданием.
Кнопка «Подсказать настройки» выставляет правильные параметры для выбранного времени.

## Как встроить в урок (Bricks, система ml-lesson)

1. Содержимое `daylight-sim.js` вставить в **Bricks → Настройки → Пользовательский код → Body (footer) scripts**
   внутри `<script>…</script>` (или подключить файлом: `<script src="…/daylight-sim.js" defer></script>`).
   Стили скрипт добавляет сам, отдельный CSS не нужен.
2. В нужном разделе урока поставить пустой **Block** с атрибутом `data-ml-widget="daylight"`
   (как остальные схемы `crop`, `slow`, `fov`, `gimbal`).
3. Необязательно: атрибут `data-start="0…4"` — с какого времени суток начать
   (0 — рассвет, 1 — утро, 2 — полдень, 3 — закат (по умолчанию), 4 — синий час).

Если `lesson-system.js` ругается на незнакомое имя виджета, можно вместо атрибута дать блоку класс `ml-daylight-sim`.

Можно смонтировать вручную: `MLDaylightSim.mount(document.querySelector('#my-block'))`.

## Технические детали

- Без зависимостей и внешних картинок, один файл ~70 КБ (без минификации).
- Внутреннее разрешение кадра 768×432, отрисовка одного кадра ≈ 7–10 мс; анимация 25 к/с,
  останавливается, когда виджет за пределами экрана или вкладка скрыта.
- Адаптивность: на ширине до 820 px экран камеры «прилипает» к верху при прокрутке настроек;
  на 375 px нет горизонтальной прокрутки.
