# Проект «Интерактивная камера Sony α7 IV»: как сделано и как повторить

Документ описывает, что было создано, из чего, в каком порядке и какими средствами, — чтобы повторить
такой же проект для другой камеры (другой Sony, Canon, Nikon, Fujifilm…).

**Готовый результат**
- 3D-модель с подсказками по кнопкам: https://matis-academy.github.io/-/sony-a7iv/
- Симулятор съёмки с меню камеры: https://matis-academy.github.io/-/sony-a7iv/shoot/
- Репозиторий: `matis-academy/-`, папка `sony-a7iv/`

---

## 1. Что получилось

| Часть | Что умеет |
|---|---|
| **3D-модель** (`index.html`, `main.js`, `parts.js`) | Камера собрана из простых фигур в браузере, вращается мышью/пальцем. 48 органов управления: наведение подсвечивает кнопку и показывает, как она называется и что делает (по официальному руководству), RU/EN, поиск, группы «верх/зад/перед/бока/низ/объектив», мобильная нижняя панель. |
| **Симулятор съёмки** (`shoot/`) | Видоискатель с 3D-сценами (парк на закате, ночная улица, стадион), 5 объективов, режимы AUTO/P/A/S/M, ISO, экспокоррекция, фокус AF-S/AF-A/AF-C/DMF/MF, области фокуса, глаз AF, стабилизатор, штатив, проводка. Всё считается по формулам оптики: экспозиция (EV), глубина резкости, угол обзора, шевелёнка, смаз движения, шум, баланс белого. Блок «Что происходит в кадре» объясняет результат. |
| **Задания** (`shoot/tasks.js`) | 9 учебных задач (боке, против солнца, гиперфокал, заморозка, проводка, «солнечные 16», следы фар, ночной портрет, баланс белого) с автоматической проверкой снимка и подсказками. |
| **MENU 1:1** (`shoot/menu.js`, `menu-data.js`) | Полное меню камеры по справочнику: 7 вкладок, 52 группы, ~260 пунктов с официальными сокращёнными названиями, значениями и заводскими значениями. ~40 пунктов реально меняют кадр (зелёная точка). «Мое меню», настройка Fn, видео-пункты серые. |
| **Справка к меню** (`shoot/menu-help.js`) | Для каждого пункта: «что это», «когда менять», расшифровка каждого значения. На ПК — по наведению мыши, на телефоне — внизу и прямо в списке значений. |
| **Тур для новичков** (`shoot/tour.js`) | При первом входе 12 шагов со стрелками по интерфейсу; повтор — кнопка «?». |

## 2. Технологии и инструменты

- **Чистый HTML + CSS + JavaScript (ES-модули), без сборщиков и npm.** Файлы открываются браузером как есть.
- **Three.js r160** — 3D. Лежит в `vendor/` (без CDN), подключается через `<script type="importmap">`.
- **WebGL-шейдеры** (`shoot/pipeline.js`) — «матрица камеры»: HDR-рендер, размытие по глубине резкости
  (физическая формула кружка нерезкости на каждый пиксель), экспозиция, баланс белого, Creative Look, шум ISO,
  зебра, выделение контуров, экспонометр (сетка яркостей 64×43 читается с видеокарты).
- **GitHub Pages** — хостинг. Settings → Pages → ветка с проектом, папка `/` (root). Корневой `index.html`
  перенаправляет на `sony-a7iv/`.
- **Python 3 + PyMuPDF + pdftotext** — разбор PDF-справочника в данные меню (`tools/menu-extract/`).
- **Playwright + Chromium** — автотесты в браузере, включая эмуляцию iPhone 13 (`tools/tests/`).
- **Node.js** — unit-тесты оптики: `node --test shoot/optics.test.mjs`.
- **Claude Code** (облачная сессия, подключённый GitHub и Google Drive). Тексты справки писали
  5 параллельных агентов по вкладкам (промпт — `tools/help-prompt.md`).

## 4. Как создавалось (по этапам)

### Этап 1. Выбор камеры и источник
Нашли самую продаваемую камеру Sony за год (α7 IV, ILCE-7M4) и официальный «Справочное руководство» (Help Guide).
Сайт Sony из облачной среды был недоступен, поэтому PDF-версию справочника положили в Google Drive, и Claude читал
её через коннектор Drive (только чтение).

### Этап 2. 3D-модель
- Корпус — вытянутый профиль с вырезом под байонет, «горб» видоискателя, рукоятка, откидной экран, объектив
  28-70 — всё из простых фигур Three.js; надписи и насечки — текстуры, нарисованные в canvas.
- Каждая кнопка регистрируется под id из `parts.js`; при наведении подсвечивается и показывает карточку.
- Тексты в `parts.js` — пересказ раздела «Названия частей» руководства, на русском и английском.
- Мобильная версия: нижняя выдвижная панель, сворачиваемый список, поле поиска 16px (иначе iPhone зумит страницу).

### Этап 3. Ядро симулятора
- Оптика в `optics.js`: угол обзора для кадра 36×24, EV = log2(N²/t) − log2(ISO/100), решение экспозиции для
  каждого режима (в т.ч. ISO AUTO с порогом выдержки 1/f), ГРИП и гиперфокальное, смаз от рук f·0,03 рад/с·t/2^ступени,
  смаз движения, кельвины → RGB.
- Экспонометр: сцена рендерится в маленькую сетку, яркости читаются обратно; режимы замера взвешивают сетку по-разному.
  Калибровка: средний кадр парка = EV 12.
- Снимок: несколько подкадров за время выдержки складываются (движение, дрожание, проводка, следы фар).

### Этап 4. Сцены, задания, тур
Три сцены с разной освещённостью (EV 15 / 12 / 5) и светом (5600 K / 4300 K / 2700 K), движущиеся объекты.
Девять заданий: у каждого стартовые «неправильные» настройки (`setup`) и функция проверки готового кадра.
Затем — сворачиваемая карточка заданий и тур со стрелками.

### Этап 5. Меню 1:1 по справочнику
1. В PDF есть таблица «Поиск функций в MENU» (у α7 IV — стр. 95–104): вкладка → группа → пункт → страница описания.
   `table.py` разбирает её по координатам текста на странице.
2. `desc.py` по номеру страницы берёт краткое описание, варианты значений («Подробности пунктов меню») и путь MENU.
3. `defaults.py` — заводские значения из таблицы «Список значений настроек по умолчанию».
4. `final.py` сводит всё в `menu-tree.json` (схема ниже).
5. `gen_menu.py` превращает его в `shoot/menu-data.js` и вносит ручные правки (склеенные «A/B»-значения, контейнеры,
   действия, дубли фото/видео). После генерации обязательно просмотреть результат глазами и поправить таблицу `OPTS`.
6. `menu.js` — интерфейс (вкладки → группы → пункты → экран значений) и **привязки** (`makeBindings`): какие пункты
   что меняют в симуляторе. Пункты без привязки просто запоминают значение.

### Этап 6. Понятная справка
Пять агентов параллельно (по вкладкам) прочитали страницы справочника и написали для каждого пункта «что это /
когда менять / что значит каждое значение» (`tools/help-prompt.md`). `merge_help.py` проверил, что все пункты
покрыты, а ключи значений совпадают с меню, и собрал `shoot/menu-help.js`.

## 5. Как повторить для другой камеры — пошагово

> Удобнее всего делать это в Claude Code с подключённым GitHub. Ниже — что сказать и что поменять.

**Шаг 0. Подготовка**
- Скопировать папку `sony-a7iv/` в новую, например `canon-r6m2/`.
- Найти официальный PDF-справочник камеры **на русском** и положить в Google Drive (или прямо в репозиторий в
  отдельную папку, если лицензия позволяет). Проверить, что в нём есть: раздел «названия частей», таблица/список
  меню, описания пунктов, список заводских настроек.

**Шаг 1. 3D-модель** — `parts.js` и `main.js`
- Промпт: *«Вот справочник <камера>. Перепиши parts.js: все органы управления из раздела “Названия частей”, с
  группами, названиями и описаниями RU/EN. Затем перестрой main.js под форму корпуса и расположение кнопок этой камеры.»*
- Приложить 2–4 фото камеры с разных сторон — так форма получится точнее.

**Шаг 2. Параметры камеры** — `shoot/optics.js`, `shoot/lenses.js`
- `SENSOR` — размер матрицы (полный кадр 36×24, APS-C ≈ 23,5×15,6 и `coc` ≈ 0,02, Micro 4/3 17,3×13 и `coc` ≈ 0,015).
- `ISOS`, `AUTO_ISO_MAX`, ряды выдержек (`SHUTTERS`, минимальная выдержка затвора).
- Сила стабилизатора: `stabStops` в `app.js` (у α7 IV 5,5 ступени).
- `lenses.js` — объективы этой системы (фокусные, светосила, минимальная дистанция фокусировки).
- Запустить `node --test shoot/optics.test.mjs`.

**Шаг 3. Меню**
- Промпт: *«Прочитай PDF через Google Drive (только чтение). Найди таблицу/список меню и построй menu-tree.json по
  схеме из PROJECT.md (раздел 6), с описаниями, значениями и заводскими значениями. Используй скрипты из
  tools/menu-extract как образец, номера страниц и форматы подстрой под этот справочник.»*
- Затем: `python3 -I tools/menu-extract/gen_menu.py menu-tree.json shoot/menu-data.js`, просмотреть меню в браузере,
  поправить в `gen_menu.py` списки `OPTS`, `CONTAINERS`, `ACTIONS`.
- В `menu.js`:
  - `ICONS`/`SHORT` — значки и короткие подписи вкладок (у Canon/Nikon вкладки другие — id вкладок берутся из
    `ICONS` в `gen_menu.py`);
  - `makeBindings` — заново сопоставить id пунктов новой камеры с ключами симулятора (замер, ББ, фокус, протяжка,
    зебра, контуры и т.д.); список ключей — объект `DEFAULTS` в `app.js`;
  - `FN_DEFAULT` — 12 пунктов быстрого меню (у других брендов — Q-меню / i-меню, суть та же).

**Шаг 4. Справка**
- Разрезать PDF на страницы, подготовить `items-*.json` по вкладкам, запустить по агенту на вкладку с промптом
  `tools/help-prompt.md`, собрать: `python3 -I tools/menu-extract/merge_help.py helpwork shoot/menu-help.js`.

**Шаг 5. Тексты интерфейса**
- Подсказки в `shoot/tasks.js` и шаги тура в `app.js` (`TOUR_STEPS`) ссылаются на названия пунктов меню — заменить на
  названия новой камеры. Заголовки в `index.html`, `README.md`.

**Шаг 6. Проверка и публикация**
- Локально: `python3 -m http.server 8765` в корне репозитория → `http://127.0.0.1:8765/<папка>/shoot/?notour`.
- Автотесты: `npm i -D playwright`, затем `node tools/tests/menu.test.mjs shots`, `hover.test.mjs`, `missions.test.mjs`
  (тесты используют id пунктов α7 IV — поправить под новое меню).
- Пуш в ветку, которую публикует GitHub Pages. После каждого изменения JS/CSS увеличивать `?v=N` в подключениях
  (см. «Подводные камни»).

## 6. Схема `menu-tree.json` (вход для `gen_menu.py`)

```json
{
  "source": "название и версия справочника",
  "tabs": [
    { "name": "Съемка",
      "groups": [
        { "name": "Кач-во изображ.",
          "items": [
            { "name": "ПерекJPEG/HEIF",          // как напечатано в меню камеры
              "mode": "photo",                    // all | photo | movie
              "help": "1–2 предложения из начала описания",
              "options": ["JPEG", "HEIF(4:2:0)", "HEIF(4:2:2)"],
              "defaults": [{ "default": "JPEG" }],
              "page": 231,                        // страница описания в PDF
              "menuPath": "MENU → (Съемка) → [Кач-во изображ.] → ..." }
          ] } ] } ],
  "customKeyDefaults": { "photo": { "Специал. кнопка 1": "Баланс белого" } }
}
```
Пункт вида `"Родитель: Пункт"` превращается во вложенный раздел; варианты протяжки `"Режим протяжки: X"` сворачиваются
в один пункт со значениями (см. `gen_menu.py`).

## 7. Подводные камни и решения

- **Кеш браузера и GitHub Pages (~10 мин).** Телефон показывал новый HTML со старыми CSS/JS. Решение — версия в адресе
  каждого файла: `app.js?v=5`, `import ... from './menu.js?v=4'`. Меняете файл — увеличиваете номер везде, где он подключён.
- **Сайт производителя недоступен из облака** — используйте PDF через Google Drive.
- **PDF «склеивает» значения** (`RAW и JPEG/RAW и HEIF`) и смешивает заголовки со значениями — всегда просматривать
  сгенерированное меню и править `OPTS` в генераторе.
- **Названия пунктов в меню сокращены** («Тчк экспономет.») — так и должно быть, это 1:1 с экраном камеры; понятность
  даёт справка.
- **Графику производителя не копировать** — значки и оформление свои, тексты — пересказ.
- **Заводские значения ≠ стартовые в симуляторе** (например, сетка включена для учёбы) — заводское всегда помечено «завод.».
- **Рендер:** при накоплении подкадров отключить `autoClear`; дальность размытия считать от ближайшего объекта;
  после смены сцены вызывать `scene.updateMatrixWorld(true)` до автофокуса.
- **Задания проверять автотестом**: «наивные» настройки должны проваливать задачу, правильные — проходить.
- **Мобильная вёрстка:** поле ввода ≥ 16px, меню — нижняя панель, видоискатель закреплён сверху, без горизонтальной прокрутки.

## 8. Хронология запросов (как шла работа)

1. 3D-модель самой продаваемой камеры с подсказками по кнопкам → публикация на GitHub Pages.
2. Правки мобильной версии (панель снизу, кнопка «спрятать», поиск).
3. Симулятор съёмки: ядро (экспозиция, ГРИП, объективы), затем сцены, задания, Fn/MENU.
4. Кнопка спуска на экране; сворачиваемые задания; тур для новичков.
5. Меню 1:1 по PDF-справочнику.
6. Мгновенная справка по наведению мыши для каждого пункта и значения.
