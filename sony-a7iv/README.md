# Sony α7 IV — интерактивная 3D-модель

Страница с 3D-моделью камеры Sony α7 IV (ILCE-7M4). Наведите курсор на кнопку, диск или разъём: деталь подсветится, а рядом появится её название и назначение (RU / EN). У кнопок с двумя функциями описание разделено на «Съёмку» и «Просмотр».

- Расположение и назначение органов управления взяты из официального руководства
  [Sony Help Guide ILCE-7M4](https://helpguide.sony.net/ilc/2110/v1/en/index.html), раздел «Names of parts».
- Модель построена процедурно на [three.js](https://threejs.org) r160. Библиотека лежит в `vendor/` (MIT), внешних зависимостей нет.
- Возможности: виды «Спереди / Сверху / Сзади / Разъёмы / Слоты / Снизу», снятие объектива (чтобы увидеть матрицу и байонет), откидывание экрана, поиск по списку, перелёт камеры к выбранной детали.

## Публикация через GitHub Pages

Settings → Pages → *Deploy from a branch* → выбрать ветку и папку `/ (root)`.
Страница откроется по адресу `https://matis-academy.github.io/-/sony-a7iv/`.

Локальный запуск: `npx http-server .`, затем открыть `/sony-a7iv/`. Через `file://` страница не заработает, потому что ES-модули требуют HTTP.

**Обновление сайта:** GitHub Pages разрешает браузерам кэшировать файлы на 10 минут. После правок в `style.css`, `main.js` или `parts.js` увеличьте номер `?v=…` в `index.html` и в импорте `parts.js` в `main.js`, иначе у посетителей может открыться новый HTML со старыми стилями.

## Симулятор съёмки (`shoot/`)

Учебный симулятор: снимаем портрет в парке и смотрим, как настройки меняют кадр. Ссылка: `https://matis-academy.github.io/-/sony-a7iv/shoot/`.

- **Режимы** AUTO, P, A, S, M, ISO AUTO и экспокоррекция. Мигающая индикация, если камере не хватает диапазона.
- **Объективы** FE 28-70 F3.5-5.6, FE 50 F1.8, FE 85 F1.8: светосила зума, минимальная дистанция фокусировки.
- **Физика:** угол обзора по кадру 36×24 мм; глубина резкости и размытие фона по формуле тонкой линзы (кружок нерезкости для каждого пикселя); экспозиция EV = log₂(N²/t) − log₂(ISO/100); шум растёт с ISO; смаз от движения и дрожания рук (правило 1/f, SteadyShot до 5,5 ступени) — при спуске кадр усредняется из подкадров за время выдержки.
- **Автофокус** по нажатию в кадре, ручной фокус, перспектива меняется с расстоянием до модели.
- **Обучение:** блок «Что происходит в кадре» и разбор каждого снимка с гистограммой и советами.

| Файл | Что внутри |
|---|---|
| `shoot/optics.js` | формулы оптики и экспозиции (тесты: `node --test sony-a7iv/shoot/optics.test.mjs`) |
| `shoot/lenses.js` | характеристики объективов |
| `shoot/park.js` | сцена «Портрет в парке» |
| `shoot/pipeline.js` | рендер: HDR, глубина резкости, экспозиция, шум, накопление подкадров |
| `shoot/app.js` | интерфейс, режимы камеры, автофокус, галерея и разбор снимков |
