# Перевод сайта matis.academy: русский → украинский

Сайт онлайн-школы видеосъёмки Matis Academy (автор — Антон Матис, видеограф). Аудитория — новички, тон дружеский, на «ты» (там, где в оригинале «вы» — оставляй «ви»).

## Формат
- Вход: `chunks/cNN.json` — массив `[id, "русская строка"]` в порядке появления на страницах (соседние строки часто — куски одного абзаца, разрезанного ссылкой или жирным: «В уроке 2 мы говорили про» + «выдержку» + «.»). Учитывай соседей, чтобы падежи и порядок слов стыковались.
- Выход: `tr/cNN.json` — объект `{"id": "український переклад", ...}` для КАЖДОЙ строки входа (ключ — id строкой). Валидный JSON, UTF-8.

## Правила
1. Переводи смысл естественным современным украинским, не калькой. Грамотно: апостроф ’ (м’який, об’єктив), «ґ» где нужно.
2. Сохраняй ровно: начальные/конечные пробелы и пунктуацию по краям строки, числа, единицы (к/с, мм, ГБ, K, Гц, f/1.8), эмодзи, HTML-сущности (&nbsp; &#8212; и т.п.), переменные/плейсхолдеры (%s, {name}, {{x}}), URL, e-mail, @ники, хэштеги.
3. Не переводи: Matis Academy, Telegram, YouTube, Instagram, Vimeo, Pinterest, DaVinci Resolve, Premiere Pro, Final Cut, CapCut, Lightroom, Blackmagic, Sony, Canon, названия форматов/кодеков/профилей (4K, Full HD, Log, S-Log3, LUT, Rec.709, H.264, ProRes, ND, ISO, FPS, B-roll, REC), английские слова в оригинале.
4. Имена: Антон Матис → Антон Матіс; Пиксель (кот) → Піксель; «Матис» в составе → «Матіс». Описывать Антона только как «відеограф» (не «весільний відеограф», если в оригинале этого нет).
5. Названия курсов/разделов: «Профессия Видеограф» / «Профессия «Видеограф»» → «Професія «Відеограф»»; «Видеограф» (курс) → «Відеограф»; мини-курс → міні-курс; «Обучение» → «Навчання»; «Скоро» → «Незабаром»; «Подробнее» → «Детальніше»; «Читать дальше» → «Читати далі»; «Наставничество» → «Наставництво»; Wiki → Wiki; «Практика» → «Практика»; тренажёр → тренажер; урок → урок; «Блог» → «Блог».
6. Термины видеосъёмки (стандарт): выдержка → витримка; диафрагма → діафрагма; экспозиция → експозиція; баланс белого → баланс білого; фокусное расстояние → фокусна відстань; глубина резкости → глибина різкості; крупность/план: общий/средний/крупный план → загальний/середній/великий план, деталь → деталь; пересвет → пересвіт; недосвет → недосвіт; провалы в тенях → провали в тінях; динамический диапазон → динамічний діапазон; цветокоррекция → кольорокорекція; монтаж → монтаж; съёмка → зйомка; снимать → знімати; кадр → кадр; объектив → об’єктив; матрица → матриця; стабилизатор → стабілізатор; гимбал → гімбал; съёмка с рук → зйомка з рук; контровой свет → контрове світло; заполняющий → заповнювальне; рисующий → малювальне; золотой час → золота година; синий час → синя година; перебивки → перебивки; задел → запас; шот-лист → шот-лист; мудборд → мудборд; референс → референс; скаутинг локации → скаутинг локації; муар → муар; фликер/мерцание → мерехтіння; шум → шум; зерно → зерно; частота кадров → частота кадрів; замедление → сповільнення; таймлайн → таймлайн; свадьба → весілля; видеограф → відеограф; оператор → оператор; заказчик/клиент → клієнт; портфолио → портфоліо; тариф → тариф; рассрочка → розстрочка.
7. Цены, даты (15.11.2026), «$», проценты — без изменений.
8. Строка, которую нечего переводить (только цифры/английский/бренд), — верни как есть.
9. Ничего не добавляй и не сокращай; не пиши комментариев внутри перевода.

После записи файла проверь: `python3 -c "import json;a=json.load(open('chunks/cNN.json'));b=json.load(open('tr/cNN.json'));m=[i for i,_ in a if str(i) not in b];print(len(a),len(b),'missing',m[:5])"` — missing должно быть пустым.
